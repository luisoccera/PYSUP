# Aviso de privacidad de PYSUP

PYSUP trata los datos mínimos necesarios para operar la cuenta: perfil, país, preferencias, plataformas seleccionadas manualmente, interacciones, reseñas, relaciones sociales, mensajes, salas, publicaciones y notificaciones.

Los clips requieren consentimiento explícito. El archivo original se almacena de forma privada, se comparte con el procesador mediante una URL temporal y se elimina al terminar o al vencer el periodo de purga. Sólo permanecen estado, candidatos confirmados/rechazados y evidencia técnica mínima. PYSUP no usa clips para entrenar modelos ni solicita contraseñas de servicios de streaming.

El usuario puede exportar sus datos y solicitar la eliminación de su cuenta desde Configuración. Los permisos RLS separan la información de cada cuenta; mensajes y salas sólo son legibles por participantes.

Antes de publicar, el propietario debe completar responsable legal, domicilio, contacto, base jurídica, proveedores, transferencias, retención exacta y derechos aplicables en cada país.
